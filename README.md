## 제출 방법

zip 제출은 없습니다. 본인 GitHub 계정에 공개 저장소 `physicalai-lv1-<이름>` 을 만들고 `lv1_module1/` ~ `lv1_module4/` 폴더에 네 과제를 담습니다. 과제별 마감 전 마지막 커밋에 태그 `lv1-module{번호}-submit` 을 달아 push 하고 저장소 URL 을 제출 폼에 등록합니다. 채점은 태그가 가리키는 커밋으로 합니다.
